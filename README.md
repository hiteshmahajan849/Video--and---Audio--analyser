# Video-and-Audio-analyser
A Python-based video analysis tool that extracts and displays important information and metadata from video files.
# Features 
Audio Analysis (Audio_task.py): Extract codec, sample rate, bit rate, channel layout, duration, and format metadata. Video Analysis (video_task.py): Extract video resolution, frame rate, video codec, audio track details, duration, bit rate, and format metadata.
# Prerequisites
Python 3.x FFmpeg / FFprobe installed and available in your system PATH.
# Usage
# Analyze Audio File
python.Audio.py
# Analyze Video File
python.Video.py
